PCB Design Assignments given by IITB Rocket Team - Avionics Subsystem:
# BMI160 IMU Breakout Board
Design a 2-layer breakout board for the Bosch BMI160 6-axis IMU (QFN-24 package).
# Basic Flight Computer with Sensors
Design a PCB which can record and store data onboard incorporating:
1.⁠ ⁠RP2040 MCU + W25Q128J flash with SOT package and XIP support + 12 MHz crystal oscillator (10-20 PPM tolerance)
2.⁠ ⁠USB-C port (try to do 90 ohm impedance matching for the differential pairs)
3.⁠ ⁠BMP280 barometric pressure sensor + BMI160 IMU + KX134 high range accelerometer
4.⁠ ⁠Voltage regulators for battery and USB
